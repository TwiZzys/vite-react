# 🚀 High-Performance React + TypeScript Vite Boilerplate

Сучасний, мінімалістичний та високопродуктивний стартовий шаблон для швидкого розгортання вебдодатків будь-якої складності. Побудований на базі чистого стеку без зайвих важких плагінів, із використанням власних кастомних системних скриптів автоматизації та збірки активів.

## 🛠 Стек технологій

* **Core:** React 19, TypeScript

* **Routing:** React Router v7

* **Bundler:** Vite 8

* **Icons:** Lucide React

* **Styling:** SCSS / SCSS Modules, PostCSS, Browserslist

* **Package Manager:** Yarn 4

## 💻 Системні вимоги та середовище (Fedora Linux)

Оскільки шаблон використовує системні утиліти для максимальної швидкості оптимізації активів, перед початком роботи на **Fedora Linux** переконайся, що встановлені необхідні пакетні інструменти.

### 1. Встановлення системних утиліт (DNF)

Виконай у терміналі команду для встановлення утиліт обробки графіки (`cwebp`, `avifenc`, `pngquant`):

```
sudo dnf install libwebp-tools libavif-tools pngquant

```

### 2. Встановлення залежностей проєкту

У кореню нового проєкту виконай встановлення пакетів через Yarn:

```
yarn install

```

```
│   ├── components/         # UI-компоненти з локальними структурами та картинками

│   ├── layouts/            # Шаблони макетів сторінок
│   ├── pages/              # Сторінки додатку

│   └── utils/              # Допоміжні утиліти

│       ├── faviconGeneration.js  # Нарізка фавіконів (Jimp), маніфесту та ін'єкція в HTML
│       ├── fontsGeneration.js    # Конвертація шрифтів (fontverter), генерація @font-face та SCSS-міксинів
│       ├── imagesConvert.js      # Оптимізація та конвертація графіки (WebP, AVIF, pngquant, cwebp, avifenc)

└── package.json

```

## 🚀 Швидкий старт

1. **Ініціалізація нового проєкту** (через системну ZSH-функцію `new-dev`):

   ```
   new-dev <назва-проєкту>
   
   ```

2. **Запуск у режимі розробки** (підіймає локальний сервер розробки, запускає моніторинг активів і відкриває браузер):

   ```
   run <назва-проєкту>
   # або через yarn:
   yarn dev
   
   ```

3. **Збірка для продакшну**:

   ```
   yarn build
   
   ```

## ⚙️ Унікальні особливості збірки (Vite Tasks)

Шаблон повністю позбавлений стандартних сторонніх важких плагінів на користь власних Node.js скриптів автоматизації:

* **SVG Pipeline (`svgSprite.js`):**
  Керує оптимізацією звичайних SVG-файлів без втрати деталізації та геометрії з Figma. Автоматично збирає глобальні й компонентні іконки у єдиний SVG-спрайт (`sprite.svg`) із розумним кешуванням через SHA-256 хеші (`.svg-cache.json`) та ін'єкцією `currentColor`.

* **Автоматика зображень (`imagesConvert.js`):**
  Гнучкий обробник графіки. У режимі розробки забезпечує швидке копіювання файлів. У продакшн-збірці задіює системні утиліти (`pngquant`, `cwebp`, `avifenc`) для квантування PNG та генерації ультра-оптимізованих форматів WebP і AVIF із підтримкою паралельної обробки батчами.

* **Автоматика шрифтів (`fontsGeneration.js`):**
  Автоматично відстежує вихідні шрифти `.ttf`/`.otf`, конвертує їх у сучасні вебформати `.woff` та `.woff2` за допомогою `fontverter`, розпізнає вагу і стиль, генеруючи правила `@font-face` та відповідні SCSS-міксини.

* **Автоматика фавіконів (`faviconGeneration.js`):**
  Генерує повний комплект фавіконів для всіх типів пристроїв на основі вихідного зображення через `Jimp`, створює `site.webmanifest` та автоматично оновлює відповідні HTML-теги у `index.html`.
